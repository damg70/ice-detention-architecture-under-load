# ICE Detention Architecture Under Load

An interactive, deterministic model of how immigration-detention
architecture responds to duration of exposure and population load. It is an
imaginative instrument for thinking about what a building can and cannot
hold. It does not describe, rate or judge any real facility.

- **The app** is in [`app/`](app/): a static site with no build step. See
  [`app/README.md`](app/README.md) to run and test it.
- **Start here:** [the project summary](summary/ICE_Detention_Architecture_Under_Load_Project_Summary.pdf).
- **The model:** [`architecture_under_load_spec.md`](architecture_under_load_spec.md).
- **Design history and open questions:** [`design_notes.md`](design_notes.md).
